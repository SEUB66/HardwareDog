# HARDWARE DOG / BRAND ASSETS

```text
source/    untouched originals, never recompressed or overwritten
web/       optimized derivatives loaded by the application and the README
social/    OG / sharing images
archive/   rejected experiments, kept for history, never loaded
```

Rules for every file here: [`docs/BRAND.md`](../../docs/BRAND.md).
Derivatives are generated by `npm run assets` in `web/`
(script: `web/scripts/build-brand-assets.mjs`), the TV companion's scenes
by `npm run companion` (scripts: `web/scripts/build-companion-scenes.mjs`
for Flipper Lab, `web/scripts/build-dog-scenes.mjs` for the dog).
Never edit them by hand.
