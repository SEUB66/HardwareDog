LE MANIFESTE / 05 LOIS

Le logiciel vous sert.
Il ne vous retient pas.

Des limites d’architecture, pas des promesses marketing. Les lois vérifiables sont testées dans le projet.

LAW_01↗

Une seule chronologie.

Le matériel, le simulateur et les enregistrements parlent le même langage. Un modèle d’événement, une horloge, une timeline pour comprendre l’incident.

ONE EVENT MODEL. ONE CLOCK.
LAW_02↻

Une panne. Un test.

Un incident enregistré peut devenir un test reproductible. Une panne rencontrée une fois aide à améliorer le diagnostic pour la suite.

INCIDENT → REPLAY → REGRESSION
LAW_03 / ANTI-SAAS⌁

Local, par principe.

Aucun compte. Aucun abonnement. Aucune télémétrie par défaut. Capturer, diagnostiquer, enregistrer, rejouer et exporter sans cloud obligatoire.

LOCAL IS THE SOURCE OF TRUTH.
Pas de courrielPas de paywall à l’exportPas de serveur de licence requis
LAW_04≠

Pas de fausse certitude.

Des faits observés, une corrélation, une cause possible et un prochain contrôle. Un diagnostic explique sa confiance et ses limites.

FACTS ≠ GUESSWORK
LAW_05◇

Les preuves restent des preuves.

Les enregistrements sont scellés par SHA-256. Une source simulée reste étiquetée SIMULATED. Un fichier altéré est signalé MODIFIED.

EVIDENCE STAYS EVIDENCE.
