03 // COMPANION TV

ONE TIMELINE. ONE INCIDENT.

Specialized tools investigate a layer.
Hardware Dog investigates the incident.

Il ne remplace pas un profileur d’alimentation, un analyseur logique ou un analyseur USB : eux vont plus profond, Hardware Dog va plus large. Un seul chien suit chaque couche, avec de vrais événements. Choisissez une chaîne.

CADRAN : chaîne suivante · POWER : écran allumé / éteint

CH 01 // IDLE / READY

Rien de branché, rien de mesuré. Hardware Dog s’ouvre NOT CONNECTED et attend que vous choisissiez une source.

OUVRIR L’OUTIL ↗

CH 02 // USB / ENUMERATE

Avec dogd sous Linux : chaque appareil USB de cet ordinateur, VID/PID, vitesse, classe et interfaces. Chaque branchement et chaque débranchement arrive sur la chronologie, horodaté.

DEMO // HD-T005 INTERMITTENT USB ↗

CH 03 // SERIAL / LIVE

La console série de n’importe quelle carte dans le navigateur : chaque ligne horodatée, les resets de la cible ; un mauvais débit est repéré, et FIND BAUD trouve le bon. Sans sonde.

DEMO // HD-T004 SERIAL FRAMING ↗

CH 04 // BLUETOOTH / SCAN

Notre propre scanner BLE, décodé en local : avec dogd sous Linux, tous les appareils autour de vous ; dans Chrome, l’appareil que vous choisissez et ses services GATT.

CH 05 // NETWORK / TEST

Des indices de caméras cachées en Bluetooth, et sur un réseau que vous choisissez et en USB avec dogd sous Linux, puis une inspection guidée. Un scan sans indice ne prouve rien, et il le dit.

04 // THE .HDLOG STANDARD

DON'T SEND A SCREENSHOT. SEND THE .HDLOG.

Chaque session est enregistrée dans votre navigateur pendant qu’elle se produit, scellée par SHA-256, et rejouée à l’identique, sans le matériel. Un atelier peut envoyer la panne d’un client à quelqu’un qui connaît la carte.

  1. 01

    RECORD

    Enregistré en local, pendant que ça se passe : chaque trame, chaque rejet, chaque commande, sur l’horloge de la sonde.

    IndexedDB · ce navigateur

  2. 02

    SEAL

    Haché par SHA-256. Hardware Dog dit si c’est la session telle qu’enregistrée, ou si des octets ont changé depuis.

    VERIFIEDMODIFIEDSIMULATED

  3. 03

    REPLAY

    Rejoué à l’identique, dans le même décodeur et avec les mêmes règles. Une panne intéressante devient un cas : un test de régression que le moteur doit continuer d’expliquer.

05 // LES OUTILS / DANS LE NAVIGATEUR

Diagnostic matériel local-first. Dans votre navigateur.

Camera Sniffer, Bluetooth Lab, Flipper Lab, USB, réseau et série : ce que chaque outil fait vraiment, et ses limites. Une démo fonctionne dans tous les navigateurs.

CAMERA SNIFFER

Caméras cachées : des indices, sans app cloud.

Repère des indices de caméras en Bluetooth, sur un réseau que vous choisissez et en USB (avec dogd sous Linux), et guide une inspection physique objet par objet. Il dit ce qu’il observe : un scan sans indice ne prouve pas qu’il n’y a aucune caméra.

OBSERVED ≠ CONFIRMED

BLUETOOTH LAB

Un scanner Bluetooth LE dans le navigateur.

Avec dogd sous Linux, tous les appareils Bluetooth LE autour de vous. Dans Chrome, l’appareil que vous choisissez dans sa liste, et ses services GATT : le scan complet du navigateur est encore expérimental.

BLE / GATT

FLIPPER LAB

Flipper Zero par Web Serial, sans app à installer.

Lire le stockage et les captures d’un Flipper Zero depuis un navigateur Chromium sur ordinateur (Web Serial).

READ, COMPARE, ARCHIVE

USB · RÉSEAU · SÉRIE

La console d’une carte, le réseau de cet ordinateur.

La console série de n’importe quelle carte dans le navigateur ; le réseau de cet ordinateur par dogd, le daemon local optionnel, et ses périphériques USB (dogd sous Linux). La sonde Hardware Dog est encore en développement.
